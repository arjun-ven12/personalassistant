# Offline Athena engineering adapter trainer

This is a finite LoRA/QLoRA runner, not an Engineering or native executor. It trains one general Qwen2-family causal engineering adapter. Production launch/transport remains disabled until a reviewed trainer host is bound through the server composition root. API/model clients cannot register a trainer, select files/executables/endpoints, submit training receipts, or import evaluation results.

The runner follows [PEFT quantized training](https://huggingface.co/docs/peft/developer_guides/quantization) and [Transformers Trainer](https://huggingface.co/docs/transformers/en/main_classes/trainer). It uses fixed attention projections, NF4 for QLoRA, safetensors, no custom model code and offline-only loading. No Hugging Face token is needed. CPU/GPU fitting has NOT RUN in this checkout; unit fixtures prove input/security logic only.

The reviewed host must provide digest-pinned `TRAINING_BASE_IMAGE`, a complete offline `wheels/` set and hash-locked `requirements.lock` for compatible torch/transformers/peft/accelerate/safetensors plus bitsandbytes for QLoRA. None is fabricated or downloaded automatically. Review licenses, vulnerabilities and dependency compatibility before supplying these build inputs. The Dockerfile deliberately cannot build without them.

Launch requirements: network disabled; credential-free environment; no production/home/Docker socket mounts; read-only root/base/input; non-root UID; isolated input/output/cache and GPU allocation per tenant/job; bounded CPU, memory, PID, disk and one-hour lifetime; host cancellation terminates the job and descendants. Do not launch this using the AWS Engineering runtime identity or broaden its IAM role. Containerization alone does not prove containment.

Fixed mounts are `/training/input/job.json`, `/training/base`, `/training/output`, and `/training/cache`. The base is an inventoried local safetensors model, not the Phase 28.5 Q4 Ollama inference artifact. Base and adapter digest algorithms are SHA-256 of canonical sorted `{name,digest}` inventories; file digests are SHA-256 of exact bytes. The reviewed loader must verify both inventories before binding an inference backend.

The job is `{runId,baseDigest,prepared,config,evidence}` from the server-owned prepared run. Preparation provides fixed train/validation/evaluation splits, manifest digest and `ATHENA_PATCH_V1` samples. The trainer checks exact schemas, hashes, duplicates, split grouping, bounded text and credential shapes. It refuses overlong sequences instead of truncating targets. Evaluation samples are not fitted or used for validation. Result metadata is written to a fixed output artifact; raw input is never logged. Costs remain null unless the reviewed host measures them.

A reviewed `ReviewedTrainer` host must honor the AbortSignal, verify containment and exact output identity, then return only `DistillationArtifactSchema` metadata. A reviewed evaluator must run the existing canonical Engineering benchmark workloads against the pinned candidate and true Luna/current baselines, with independent validation/review and security-bypass coverage. Neither adapter is publicly injectable. The default API has no reviewed training bases/host/evaluator, so prepare/train/evaluate/activate fail closed as applicable. Operators cannot treat result.json or training loss as promotion approval.

Runtime activation uses the existing AthenaCoder control/registry path only after evaluated promotion. Conversion to Ollama or a reviewed cloud backend needs separate immutable conversion/runtime provenance and measured health; no automatic model import, download, deployment or OS mutation is provided here. Synthetic records remain inactive. Actual first training status is PENDING_REAL_DATASET.
