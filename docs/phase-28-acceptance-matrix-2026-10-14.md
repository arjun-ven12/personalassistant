## Reproducible environment commands

From repository root, after creating a disposable test-named PostgreSQL database and ensuring `DATABASE_URL` is unset or different:

```sh
TEST_DATABASE_URL='postgresql://test_user:password@127.0.0.1:5432/assistant_test?sslmode=disable' pnpm phase28:postgres:acceptance
```

The URL above is a shape/example, not a credential or a completed run. The harness refuses absent/unsafe URLs, creates isolated schemas, applies migrations, and runs the fixed PostgreSQL test list. It does not replace a production API process restart acceptance.

From `apps/android`, with JDK 17 and SDK platform 35/build-tools 35.0.0 installed:

```sh
./gradlew testDebugUnitTest assembleDebug --no-daemon
./gradlew connectedDebugAndroidTest --no-daemon
```

The second command requires a running compatible emulator/device. Neither command ran successfully in this environment.
