# Working Style

Working style records model the owner’s preferred way of building:

- architecture-first;
- reusable code;
- security-first;
- performance-first;
- documentation before release;
- incremental development;
- review before merge;
- fail closed;
- minimal AI dependency.

The Planner receives active working style records as context. The records are
owner-scoped, explainable, versioned, and reversible.
