# Learning Studio

Learning Studio is the owner-visible inspection surface for Phase 19C data. The
backend now exposes the required data groups:

- overview statistics;
- recent events;
- candidates;
- active preferences;
- habits;
- sequences;
- suggestions;
- conflicts;
- timeline;
- explanations.

The first backend implementation supports the data model and APIs. A richer web
UI can layer on these endpoints without changing the learning authority model.
