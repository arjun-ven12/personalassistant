# Decision Preferences

Decision preferences tell the Planner how Alexa should choose among safe,
approved options.

Default preferences include:

- prefer local execution;
- minimize token usage;
- prefer semantic integrations;
- avoid UI automation;
- prefer deterministic execution;
- prefer reviewed providers;
- prefer existing workflows.

Preferences are advisory context. They never bypass policy, approval, provider
health, trusted applications, emergency stop, or semantic verification.
