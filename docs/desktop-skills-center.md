# Desktop Skills Center

Desktop Skills Center is the dashboard surface for Phase 17F.

It displays:

- planner-visible desktop skills;
- running, paused, awaiting-approval, completed, failed, and cancelled
  workflows;
- current skill and current step;
- execution graph nodes and dependencies;
- variables and preserved context;
- approval checkpoints;
- failures and recovery suggestions;
- metrics and execution history;
- explicit safety indicators showing pixel, OCR, coordinate, computer-vision,
  hidden-capability, and automatic-skill-modification paths are disabled.
