# Personality Simulation

Personality simulation previews how different profiles shape a response without
calling an AI model.

Supported default previews include Founder, Developer, Research, Presentation,
Focus, and related profiles. Each simulation records:

- input;
- profile name;
- deterministic response preview;
- traits applied;
- `aiUsed: false`;
- timestamp.

Simulation is inspection metadata only. It does not execute Planner workflows or
modify saved personality traits.
