# Knowledge and Memory Integration

The knowledge graph does not replace memory.

Memory remains the record of experiences, decisions, summaries, preferences, and
retrieval seeds. The graph promotes only durable, high-confidence memories into
structured entities and relationships.

Promotion is deterministic:

- important memory
- sufficient confidence
- sufficient evidence
- owner-scoped source

The original memory is preserved. The promotion record stores the memory ID,
status, confidence, and produced graph IDs.
