# Knowledge Ingestion

Initial ingestion sources are deliberately bounded:

- trusted applications from the Universal Application Adapter Framework
- registered repositories
- registered workflows
- registered agents
- durable memories promoted by deterministic criteria
- explicit owner-scoped graph API requests

Ingestion does not scrape arbitrary UI, crawl arbitrary files, read secrets, or
trust browser/document content as instructions.

Memory promotion requires sufficient importance, confidence, and evidence. It
creates graph entities from durable memory while preserving the original memory
record.
