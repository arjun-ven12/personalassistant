# Application Center

The Application Center extends the Applications dashboard with Phase 17E
adapter controls.

It displays:

- trusted applications and revocation status;
- trust level and security profile;
- granted adapter permissions;
- discovered capabilities;
- profile and optional plugin records;
- adapter instances and versions;
- health, diagnostics, metrics, synchronization context, and lifecycle events;
- explicit framework indicators showing that pixel, OCR, coordinate replay, and
  untrusted application control are disabled.

The older application metadata registry remains intact. Application Center
trust is an additional adapter layer and does not grant direct OS control.
