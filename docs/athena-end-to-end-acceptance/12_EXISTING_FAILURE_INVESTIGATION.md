## Direct probes

The unchanged exported discovery schema rejects the current-home fixture path, accepts a synthetic canonical `/Users/.../Applications/...app` path, and accepts `/Applications/...app`. This probe uses schema validation only and performs no filesystem access or app launch. It confirms the invalid root, rather than merely inferring “macOS-only” from the test filename.

Python probes report version **3.10.12**, `hashlib.file_digest` **absent**, and the distribution-backported `extractall(filter=...)` argument **present**. The observed immediate blocker is therefore the missing digest API; do not guess that every later Python feature is absent. The source builder's reviewed Python 3.12 target remains the intended acceptance environment.

`evidence/drafts/failure-investigation.json` contains all six assertion names, three rerun outcomes, probe results and classification. No raw credentials, personal home path or private corpus content is copied. Existing local fixture changes in the original preserved checkout were not imported silently.

## Recommended separate corrections

1. **Corpus:** provide a reviewed, repository-contained synthetic corpus for deterministic compiler/runtime unit tests. Keep full canonical-corpus acceptance explicit and rights-reviewed; never depend on a developer's Downloads folder or treat a missing external fixture as a passing test. Preserve the substantive profile/negative-example/import assertions in their appropriate scope.
2. **Discovery:** build a hermetic unit fixture with controlled filesystem/home metadata under syntactically valid macOS roots, while keeping canonical path restrictions unchanged. Accept real discovery separately on a Mac. Do not solve the test by allowing arbitrary Linux host roots in product contracts.
3. **Image builder:** select the declared Python 3.12 CI/developer toolchain explicitly and add a clear minimum-version preflight. Keep digest verification, traversal/symlink/duplicate/quota checks and extraction policy. Do not bypass them or introduce a skip to turn an unsupported environment green.

These changes belong to a separate portable-test/toolchain slice. The six assertions remain failed in current full-suite evidence, and real Android/Mac acceptance remains blocked.
